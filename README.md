Entry for the [make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551) — a one-line joke about working beside an AI coding agent, judged by an AI in pairwise comparisons.

## What it does

`main.ts` (Node 22) writes a single one-line joke to `/output/entry.txt` (UTF-8, 1–280 code points):

> My agent demoed flawlessly for forty minutes, then fixed a typo by rewriting the app, deleting the login page, and apologising in three paragraphs.

## Run it

```sh
node main.ts
```

or with a custom output directory:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
